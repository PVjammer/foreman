## start
- State what the POC needs to demonstrate and how you'll know.

## work
- Build the smallest thing that demonstrates it, with a README covering how to run it and what it shows. Commit on your branch.

## closeout
- Docs: record what was learned, what didn't work, and the open questions; link the POC's README.
- Follow-ups: what it would take to turn the POC into real work (suggested features or tickets).
